## 🇫🇷 Français

### Description
**Dys-Helper** est un assistant de lecture et de mise en page inclusive conçu pour faciliter l'accès au texte pour les utilisateurs dyslexiques. Initialement conçu comme une application web PHP, cet outil permet d'ajuster dynamiquement la typographie, les espacements, et d'ajouter des aides visuelles comme la segmentation syllabique ou une règle de lecture.

### Fonctionnalités Clés
* **Personnalisation Typographique** : Choix de polices adaptées (OpenDyslexic, Lexend, Atkinson Hyperlegible).
* **Aides Visuelles** : Segmentation syllabique colorée, mise en évidence des confusions de lettres (b/d, p/q), et mode règle de lecture.
* **Accessibilité Audio** : Synthèse vocale (TTS) avec suivi du texte en temps réel (mode karaoké).
* **Gestion de Profils** : Sauvegarde des réglages personnalisés pour différents élèves ou besoins.
* **Import/Export** : Support des fichiers .docx et .txt, et export de configurations.

## 🇺🇸 English

### Description
**Dys-Helper** is an inclusive layout and reading assistant designed to improve text accessibility for dyslexic users. Originally developed as a PHP web application, this tool allows dynamic adjustments to typography, spacing, and adds visual aids such as syllable segmentation or a reading ruler.

### Key Features
* **Typographic Customization**: Selection of specialized fonts (OpenDyslexic, Lexend, Atkinson Hyperlegible).
* **Visual Aids**: Colored syllable segmentation, letter confusion highlighting (b/d, p/q), and reading ruler mode.
* **Audio Accessibility**: Text-to-Speech (TTS) with real-time word highlighting (karaoke mode).
* **Profile Management**: Save personalized settings for different students or specific needs.
* **Import/Export**: Support for .docx and .txt files, and configuration export.
